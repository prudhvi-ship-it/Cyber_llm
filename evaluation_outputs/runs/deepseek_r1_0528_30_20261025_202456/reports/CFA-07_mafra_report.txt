Originally published in July 2023. Updated September 2025. OS Command Injection is a web application vulnerability that can lead to arbitrary command execution on the underlying operating system. Attackers exploit command injection vulnerabilities by supplying malicious input to operating system commands executed by an application. Successful exploitation can allow attackers to retrieve sensitive data, escalate privileges, and move laterally within a network. Strong input validation is the preferred defense against command injection vulnerabilities. Avoiding operating system command execution entirely is the most effective mitigation. What is OS Command Injection? OS Command Injection is a web application vulnerability that allows attackers to execute arbitrary commands on the underlying operating system. Because successful exploitation can lead to full command execution on a target system, command injection vulnerabilities are often considered among the most severe web application vulnerabilities.
